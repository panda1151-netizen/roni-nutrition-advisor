# Roni Nutrition Advisor

אפליקציית ווב מוביילית בעברית לניהול התפריט של רוני.

## מה עובד בגרסה הסטטית
- מעקב אחר 4 ארוחות
- החלפות מאותה קבוצת מזון
- תוספת גמישה
- דיווח רעב
- מעקב מים / צעדים / שינה
- יומן יום
- סיכום שבוע
- שמירה מקומית בדפדפן באמצעות localStorage

## AI
הקובץ `server.mjs` מיועד לחיבור מאובטח ל-OpenAI דרך שרת.
GitHub Pages הוא אירוח סטטי בלבד, ולכן צ'אט AI וזיהוי תמונות דורשים backend נפרד.

אין לשמור OPENAI_API_KEY בתוך index.html או בכל קובץ ציבורי בצד הלקוח.
